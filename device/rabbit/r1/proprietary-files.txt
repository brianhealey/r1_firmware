# Vendor blobs required by the rabbit r1.

# Format: one path per line, relative to the root of the vendor partition
# (or system_ext). `extract-files.sh` reads this list to pull blobs from a
# connected stock device; `setup-makefiles.sh` turns it into Android.mk.
#
# This inventory is INCOMPLETE. It lists the MediaTek telephony/IMS/vcodec
# blobs identified by the community (reference only) plus the r1-specific
# charger/vtservice binaries. The full vendor set — GPU (Mali-G72), camera,
# audio DSP, WiFi/BT (MT6631N) firmware, sensors — still needs to be
# enumerated from a stock device. See docs/vendor-blobs.md.
#
# Blobs may alternatively be sourced from the LineageOS-style vendor tree
# RabbitHoleEscapeR1/vendor_rabbit_r1 (see docs/vendor-blobs.md); that tree
# carries the telephony/IMS subset below.
